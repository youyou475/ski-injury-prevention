# 雪线之上 · 预防滑雪运动损伤交互式科普学习系统

> Above the Snowline — An Interactive Panoramic Learning System for Skiing Injury Prevention

基于 **4K 全景视频 + 原生 WebGL + Three.js** 的滑雪运动损伤预防科普作品。四个学习模块共享同一套积分与学习档案——从"看讲解"，到"动手推演损伤机理"，再到"在 3D 雪场里亲身体验"。

本仓库为**作品本体（Web 应用）源码**，即运行所需的全部文件。

---

## ✨ 模块一览

| 模块 | 内容 | 技术实现 |
|---|---|---|
| 🎬 **视频学习** | 23 段全景讲解 + 4 个雪场情境决策 + 23 张知识卡 | 自研零依赖 WebGL 等距柱状反投影播放器，双 `<video>` 缓冲无缝切换 |
| 📝 **知识测试** | 前测 / 后测各 6 题，可自由选择顺序 | 题库驱动，答题即时解析 |
| 🔬 **损伤机理 3D 实验室** | 膝关节前交叉韧带、桡骨远端骨折、踝内翻扭伤、冻伤血管收缩 | Three.js 程序化建模 + 力度滑杆实时驱动损伤过程 |

**统一积分与档案**：四模块共享 5 级称号体系（雪场访客 → 雪线守护者）、积分流水、学习时间线、CSV 导出；`award(key, ...)` 幂等发分，重玩不刷分。

## 🚀 运行

浏览器在 `file://` 协议下禁止 `fetch()` 读取本地 JSON，也无法加载 WebGL 视频纹理与 glTF 模型，**必须通过 HTTP 服务打开**。且服务需支持 Range 请求，否则视频无法 seek、进度条失效。

```bash
# 任选一种支持 Range 的静态服务器
npx serve -l 8000          # 推荐
# 或
python3 -m http.server 8000   # ⚠️ 不支持 Range，视频 seek 会失效
```

启动后访问 `http://localhost:8000`。

> 3D 实验室与全景滑雪场不依赖视频，打开即可体验。

### ⚠️ 视频素材需自行放入

为保证仓库体积，**23 段全景视频（约 557 MB）未纳入版本控制**。运行视频模块前，请将视频放入：

```
assets/video/<slug>.mp4
```

slug 列表见 `data/content.json` 中 `nodes[].slug`（例如 `00_intro.mp4`、`07_knee.mp4`）。视频为 2560×1280 等距柱状投影 H.264，建议 GOP ≤ 48 帧以保证 seek 精度。

## 🛠 技术要点

- **零依赖全景播放器**：原生 WebGL 等距柱状反投影，支持拖拽 / 滚轮 / 键盘 / 陀螺仪；WebGL 不可用时自动降级为平面播放。
- **视频纹理的 Metal/ANGLE 兼容问题**：直接把 `<video>` 上传为纹理在部分图形后端会静默失败（`glError=0` 但采样全黑），本项目改用 **2D canvas 中转**（`drawImage(video) → canvas → texImage2D`）解决。
- **GOP 结构**：`h264_videotoolbox` 会忽略 `-g` 参数，导致全片仅 1 个关键帧、seek 完全失效；改用 `libx264` 并显式 `-g 48 -keyint_min 48 -sc_threshold 0`。
- **地形一致性**：Blender 建模脚本与 `js/ski3d.js` 共用逐行相同的高度函数，保证角色贴地与站点坐标精确对应；场景静态景物合并为 33 个网格（约 44 次绘制调用）。
- **字幕**：`data/narration.json` 时间轴驱动，按 `。！？；` 断行提升可读性。
- **数据与逻辑分离**：知识卡、题库、机理、站点内容全部在 `data/*.json`，改内容无需动代码。

## 📖 内容与素材说明

- 视频画面与现场讲解录音来自团队实地拍摄的原始素材；字幕由原声语音转写生成并经人工校对，**作品不含 AI 合成人声与 AI 生成画面**。
- 知识卡、情境决策、测验题库依据公开运动医学资料撰写，并在界面内标注资料依据，**待专业医学复核**。
- 3D 模型（滑雪者、骨骼韧带、雪场地形 / 树木 / 缆车等）均为**程序化几何体搭建**，未使用外部模型素材。
- 本项目为科普演示用途，不构成医学诊断或治疗建议；实际滑雪请在专业教练指导下进行。
